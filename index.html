0. 【重大变化提醒】⚠️

A股 ERP 由 6.06% 回落至 5.81%，从「低估（机会）」档位降至「正常」档位。

  • 含义：股债性价比的极端吸引力有所收敛，A股相对债券的“便宜程度”已从左侧深度布局区回到中性区间，不再是“闭眼加仓”的极端信号。
  • 归因：更可能是权益端估值抬升（沪深300分位已升至 67.62）叠加 10Y 国债收益率处于 1.5874 的历史低位，双向挤压 ERP。
  • 配置影响：A股由“高确定性左侧机会”转为“结构性机会为主”，建议从“全面加仓”切换为“精选结构 + 控制节奏”，不宜追高。

1. 【市场核心结论摘要】

全球呈现“美股极贵 + 美债实际利率高企 + 中国资产中性偏合理”的格局：美股 Shiller PE 39.85、ERP 转负，风险溢价几乎消失；A股/港股估值处于中性区间、ERP 刚退出低估，性价比尚可但边际减弱。当前主要矛盾是“高企的美国实际利率（2.66%）对全球风险资产的估值压制”与“A股内部情绪回暖”之间的拉锯，配置上宜“A股/港股中性偏积极、美股谨慎、久期与黄金做防御”。

2. 【各市场详细扫描】

🟡 A股：中性合理，性价比边际减弱

  • ERP 5.81%（阈值 >6.0 低估 / <3.5 高估）→ 正常，刚退出低估区。
  • 沪深300估值分位 67.62（<20 低估 / >80 高估）→ 中性偏上，估值修复已走了一段。
  • 交叉验证：ERP 与分位“双中性”，不属于高性价比左侧布局区，也不构成高估风险，属于“持有为主、结构为王”的阶段。
  • 结论：中性，结构性做多。

🟡 港股：中性，估值有安全垫但缺乏催化

  • 恒生 PE 11.0x（<10 低估 / >16 高估）→ 正常偏低。
  • 恒生 PB 分位 52.46（<15 低估 / >85 高估）→ 中性。
  • 解读：绝对估值不贵，PB 分位中位，下行有安全垫、上行需外部流动性（美债利率回落）配合。当前美债 4.88% 高位对其形成压制。
  • 结论：中性，逢回调可小幅配置。

🔴 美股：高估，风险溢价消失

  • Shiller PE 39.85（>35 高估）→ 高估，处于历史极值区。
  • ERP -0.15%（<1.0 高估）→ 高估，股权风险溢价为负，股票相对债券毫无补偿。
  • 叠加隔夜大涨（纳指 +2.74%、标普 +2.35%、道指 +2.15%），情绪偏亢奋，估值与情绪双高，追高风险大。
  • 结论：高估，注意防范风险，不宜追高。

🟢 国内宏观：利率极低，债券性价比高但已充分定价

  • 10Y 国债 1.5874%（<1.8 低估）→ 低估（利率低=债券价格高）。
  • 解读：低利率环境对权益估值形成支撑（DCF 分母端友好），但也意味着债券进一步下行空间有限、票息保护薄。对A股是“估值托底”而非“强驱动”。
  • 结论：债券中性偏谨慎（久期不宜过长），对权益构成温和支撑。

🔴 海外利率：实际利率高企，全球估值之锚偏紧

  • 美国实际利率 2.66%（>2.5 高估）→ 高估（对风险资产不利）。
  • 美债 10Y 4.88% 高位，实际利率 2.66% 是全球风险资产估值的“地心引力”，压制高估值资产（尤其美股、成长股）。
  • 结论：海外利率环境偏紧，是全球风险资产的主要逆风。

3. 【全球宏观与无风险利率面】

  • 美债 10Y 4.88%：高位运行，实际利率 2.66% 偏紧，对全球高估值资产构成持续压制，是当前最重要的宏观逆风变量。
  • 中美利差：中国 10Y 仅 1.5874%，中美利差深度倒挂，对人民币资产估值形成外部约束，但汇率端暂稳。
  • 汇率 USD/CNY 6.6712~6.6713：人民币处于相对偏强区间，汇率对A股/港股不构成额外压力，反而略偏友好。
  • 黄金 XAU/USD $4130.27（-0.26%，基准 $4000）：高于基准、远离 $3600/$3500 预警线，避险与抗通胀需求仍在，可作为组合对冲工具。
  • 海外市场：隔夜美股三大指数齐涨（纳指 +2.74% 领涨），风险偏好短期回暖，但建立在极贵估值之上，持续性存疑。

4. 【A股微观情绪与资金面】

  • 赚钱效应 🟢 强：上涨 4217 家 vs 下跌 803 家，涨停 22（真实涨停 16）、跌停 0，普涨格局、无恐慌盘，情绪明显偏暖。
  • 活跃度 80.71%：交投活跃，市场参与度高。
  • 成交额：两市合计 14945.54 亿元（沪 6833.08 亿 + 深约 8112.46 亿），量能维持万亿以上，属健康水平，支撑结构性行情。
  • 主力资金 🟢：净流入 128.57 亿元（净占比 0.87%），资金面偏积极，但净占比不高，属温和流入而非强攻。
  • 板块轮动：领涨 燃气(+3.58%)、煤炭开采(+3.53%)、元件(+2.57%)——低估值红利/资源 + 部分科技；领跌 能源金属(-2.34%)、光伏设备(-2.05%)、教育(-1.66%)——新能源与部分成长承压。
  • 解读：情绪面“普涨 + 温和流入 + 红利资源领涨”，呈现“防御性做多 + 高低切换”特征，说明资金在估值中性环境下更偏好确定性（红利/资源），而非追高成长。
